# Shaista Ansari — Developer Portfolio

A responsive React + Vite portfolio based on the resume supplied for this project.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed in the terminal.

## Before publishing
- Replace the GitHub profile links on each project card with the exact repository URL once the repositories are public.
- Confirm contact details and profile URLs.
- Optional: add a downloadable resume PDF and link it from the hero section.

## Deploy
Push this folder to a GitHub repository and import it into Vercel. Build command: `npm run build`. Output directory: `dist`.
